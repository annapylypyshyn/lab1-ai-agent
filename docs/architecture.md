# Архітектура AI-агента

**Проблеми, які вирішує агент:**
Автоматизація рутинних задач зі створення базової структури проєкту, налаштування системи складання Cargo, написання базових тестів та конфігурації кросплатформного CI/CD для Rust.

**Skills (Навички):**
- `project-scaffold`: створює структуру проєкту та базовий маніфест `Cargo.toml`.
- `build-and-test`: налаштовує юніт-тести та логіку складання через `cargo`.
- `github-actions`: генерує кросплатформний CI workflow.

**Commands (Команди):**
- Доступні команди: `git-init`, `create-project`, `create-build`, `create-actions`, `check`.
- Оркестратор: `init`.

**Передача даних:**
Команди виконуються послідовно через оркестратор `init`. Результати роботи попередніх команд (новостворені файли та конфігурації) є вхідними даними для наступних кроків.

**Обробка помилок:**
Оркестратор припиняє виконання сценарію, якщо будь-яка з команд або перевірок завершується з помилкою. Команда `check` гарантує валідацію фінального результату перед завершенням роботи оркестратора.
